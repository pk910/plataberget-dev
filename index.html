Join the Network

The validator set is open and permissionless. Spin up a node with any client pair using the ethpandaops/<client>:glamsterdam-devnet-8 images, sync from a checkpoint sync provider below, and deposit test validators via the deposit contract. Test ETH is available from the faucet.

Important Notice

Platåberget is the public testnet for Gloas / the Glamsterdam upgrade (enshrined proposer-builder separation, block-level access lists, gas repricing and more). Use it to test client software, staking setups, builders, and infrastructure against the new fork — it is expected to stay alive until Glamsterdam ships on mainnet. For testing decentralized applications, smart contracts, and other EVM functionality, please use Sepolia.

Launched: Aug 13, 2026 • EOL: when Glamsterdam ships on mainnet
